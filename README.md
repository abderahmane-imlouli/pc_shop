# PC Shop Website

Simple computer shop website built during my early web development learning journey.

This project represents one of my first attempts at building a full website interface using basic web technologies.

## Features

- Product showcase for computers and hardware
- Simple and clean layout
- Responsive design basics
- Navigation between pages

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap

## Purpose of the Project

This project was created to practice:

- Structuring web pages
- Building layouts with HTML & CSS
- Basic JavaScript interaction
- Creating a simple e-commerce style interface

It helped me understand how websites are structured before moving to more advanced frameworks and backend development.

Completed as a learning project.
